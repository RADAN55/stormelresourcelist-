# Bilingual Spanish Resources, K-12

**EL Publishing**

A searchable directory of 201 entries (74 resources) for English, math, history and science in elementary, middle and high school. Each entry says what is in Spanish, the grades, the cost, one classroom use and a one-line Spanish description. EN/ES toggle, level tabs, subject filters.

Compiled November 15, 2026. Entries marked "Not rechecked" are home-page addresses that were not reopened.

Deploy: `index.html` at the repo root, then Settings > Pages > main / root.
