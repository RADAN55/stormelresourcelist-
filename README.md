# Bilingual Spanish Resources, K-12

**EL Publishing**

A searchable directory of 229 entries for English, math, history and science in elementary, middle and high school. Each entry says what is in Spanish, the grades, the cost, one classroom use and a one-line Spanish description. EN/ES toggle, level tabs, subject filters, and a tab for Arabic, Vietnamese, Chinese and Haitian Creole resources.

Compiled November 15, 2026. Entries marked "Not rechecked" are home-page addresses that were not reopened.

Deploy: `index.html` at the repo root, then Settings > Pages > main / root.
